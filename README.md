# AI Learning Worksheet Generator

An interactive web application for creating production-ready AI assets through guided worksheets. Generate Skill Registries, Agent Identities, Workflow Blueprints, and MCP Server configurations through an intuitive step-by-step questionnaire interface.

## Features

- **Skill Registry Generator**: Create production-ready skill specifications with input/output JSON schemas
- **Agent Identity Builder**: Design complete agent identity documents with system prompts and tool capabilities
- **Workflow Blueprint Creator**: Build deployable workflow configurations with triggers and error handling
- **MCP Server Registry Generator**: Configure MCP server integrations with security policies

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Technology Stack

- React 18 + TypeScript
- Tailwind CSS
- Vite
- Lucide React Icons

## Export Formats

Each worksheet can be exported as:
- **Production-Ready Asset**: The actual registry document (Skill, Agent, Workflow, or MCP)
- **PDF**: Formatted worksheet document
- **HTML**: Standalone HTML file
- **Markdown**: Markdown formatted document
- **JSON**: Raw JSON data
